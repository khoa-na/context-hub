LLM Wiki Starter

Upload a file, turn it into Markdown, then ask grounded questions.

This starter keeps things intentionally small: upload a text-based file, store a Markdown version, and run document Q&A through the Google Gemini API.

Supported in this version

  • .txt, .md, .json
  • .csv, .tsv, .html, .docx
  • source code files like .js, .ts, .py
